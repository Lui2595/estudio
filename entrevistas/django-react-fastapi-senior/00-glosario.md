# Glosario — di el significado la primera vez

En entrevista senior, si usas la sigla, **nómbrala**. Ej.: “ACID — Atomicity, Consistency, Isolation, Durability”.

|-------|----------------|------------|
| ORM | Mapeo objeto-relacional | Object-Relational Mapping |

| FK | Clave foránea | Foreign Key |
| M2M | Muchos a muchos | Many-to-Many |
| N+1 | 1 query de lista + N de relaciones | One list query + N relation queries |
| JOIN | Unión de tablas en SQL | SQL join |
| ACID | Atomicidad, Consistencia, Aislamiento, Durabilidad | Atomicity, Consistency, Isolation, Durability |
| DRF | Django REST Framework | Django REST toolkit |

| API | Interfaz de programación de aplicaciones | Application Programming Interface |
| HTTP | Protocolo de transferencia de hipertexto | Hypertext Transfer Protocol |

| TTL | Tiempo de vida | Time To Live |

## Frases que suenan senior (úsalas 1 vez, no 10)

- “I’d measure first.”
- “Trade-off is memory vs extra queries.”
- “Same process is simpler; a queue is durable.”
- “I modularize for cohesion, not for file count.”
